## 3 · 仍然不支持（截至 2.35.1 未见任何版本加入）

- `icon-url`（静默忽略）
- `[URL Rewrite]` 段
- `[SSID Setting]` 段（被自研 `subnet` 组类型取代，语法不同）
- `USER-AGENT` 之外的 `URL-REGEX` 规则
- Surge 4/5 大部分 `[General]` DNS 加固键（`encrypted-dns-server` 等，见 `docs/01` §3.3）
- MITM（Android 平台限制）

## 4 · 修正本仓旧结论（2026-10-10 依 release notes 订正）

| 旧结论（docs/01 初版） | 现状 |
|:--|:--|
| `USER-AGENT` 规则不支持 | **mobile-2.29.2 起支持**：按 User-Agent 通配匹配路由 HTTP 流量，要求 Android 10+ 且开启 VPN HTTP Proxy |
| `block-quic` 属「Surfboard 无对应实现」的 General 键 | **mobile-2.31.1 起支持 `block-quic` 代理参数**（在代理行上，非 `[General]` 键）。General 级键仍无对应实现 |

> 结论：**能力边界在快速移动**。凡引用「不支持」的判断，都要注明版本日期，
> 并定期对照 releases 复查。
